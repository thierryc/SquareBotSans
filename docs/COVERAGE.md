# Coverage Notes

Square Bot Sans focuses on Latin-script typography with broad pan-European and Vietnamese coverage.

Current source inventory from Glyphs MCP:

- 947 glyphs total
- 909 exporting glyphs
- 574 encoded glyphs
- Uppercase, lowercase, accents, small caps, punctuation, figures, currency symbols, math symbols, arrows, marks, stylistic alternates, and ligatures

Discretionary ligature coverage includes technical/code operators such as `<-`, `->`, `=>`, `=<`, `!=`, `>=`, `<=`, `<>`, `<|`, and `|>`. The `!=` ligature uses the not-equal symbol design, while `=>` and `=<` use arrow components for consistency with the existing arrow ligatures. Arrow coverage includes U+2190 through U+2199, including up/down and diagonal arrows.

Indicative language support includes Western European, Central European, Baltic, Turkish/Azeri Latin, Romanian, Vietnamese, and related Latin-script text. Full coverage should be verified with a generated Unicode/CLDR report before a formal release.
